# Proyek Membangun CI/CD Pipeline dengan Jenkins

## 📌 Ringkasan Proyek
Dalam proyek ini, saya membangun **Continuous Integration & Continuous Deployment (CI/CD) Pipeline** menggunakan **Jenkins** untuk mengotomatisasi proses pengujian dan deployment aplikasi React.

## ✅ Kriteria yang Dipenuhi
- Menggunakan **source code React App** dari repository Dicoding.
- Mengaktifkan fitur **Signup** dan membuat akun baru di Jenkins.
- Membuat **Jenkins Pipeline Baru** sesuai ketentuan yang diberikan.
- Menggunakan **Scripted Pipeline** dalam Jenkinsfile.
